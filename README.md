# الجذاذة النموذجية (`com.l3abed.jadhadha`)

تطبيق أندرويد متكامل لإعداد وتحرير وتفريغ وتصدير الجذاذات التربوية لمادة اللغة العربية بالسلك الثانوي الإعدادي وفق التوجيهات التربوية الرسمية لوزارة التربية الوطنية والتعليم الأولي والرياضة بالمملكة المغربية (مرجع «المختار في اللغة العربية»).

---

## المميزات الأساسية

1. **دعم المكونات الديداكتيكية الثلاثة**:
   - **النصوص القرائية** (حصتان — 7 مقاطع بيداغوجية رسمية).
   - **الدرس اللغوي** (حصة واحدة — 4 مقاطع مع جداول الظواهر الصرفية والتركيبية المتداخلة).
   - **التعبير والإنشاء** (4 حصص: الاكتساب، التطبيق، الإنتاج، التصحيح والدعم — 16 مقطعاً).
2. **استيراد وتفريغ الجذاذات (`DOCX` / `TXT` / `PDF`)**:
   - قراءة محلية كاملة لملفات `.docx` و`.txt` مع الحفاظ على الجداول المتداخلة، الخلايا المدمجة (`gridSpan` / `vMerge`)، الترويسات والتذييلات، واتجاه الكتابة العربي (`RTL`).
   - تفريغ ملفات `PDF` وتصنيف العناصر غير المصنفة اختيارياً عبر واجهة `Gemini API`.
3. **التصدير القياسي إلى `Word (.docx)` و`Python (python-docx)`**:
   - توليد ملفات `.docx` متوافقة مع `Microsoft Word` و`LibreOffice` مباشرة من الهاتف دون الحاجة إلى اتصال بالإنترنت.
   - تصدير بيانات الجذاذة بصيغة `JSON` وسكريبتات `python-docx` المستقلة لجميع المكونات.
4. **قاعدة بيانات محلية موثوقة (`Room Database v5`)**:
   - حفظ الجذاذات والمرفقات محلياً مع ترحيلات آمنة (`Migrations 1..5`)، حماية من الكتابة القديمة (`Stale Write Protection`)، وآلية مصالحة تلقائية بين قاعدة البيانات ونظام الملفات (`reconcileStorage`).

## متطلبات البناء والتشغيل

- **JDK**: إصدار `17` أو `21` (مُختبر على `OpenJDK 21.0.10`).
- **Gradle**: إصدار `9.3.1` عبر `Gradle Wrapper` المدمج (`./gradlew`).
- **Android SDK**: `compileSdk 36`, `targetSdk 36`, `minSdk 24`.
- **Python 3** (اختياري لاختبارات توليد `python-docx`): مع مكتبة `python-docx`.

### أوامر البناء والاختبار من نسخة نظيفة

```bash
# 1. تشغيل سكريبت التحقق الشامل (فحص الأسرار + البناء + الاختبارات + Lint + فحص DEX)
chmod +x gradlew scripts/verify.sh
./scripts/verify.sh

# 2. أو تشغيل مهام Gradle مباشرة
./gradlew assembleDebug testDebugUnitTest lintDebug
```

## إعداد مفتاح `Gemini API` (اختياري)

لا يتضمن التطبيق ولا ملف `APK` أي مفتاح `Gemini API` مدمج:
- جميع ميزات التحرير، المعاينة، استيراد `.docx`/`.txt`، القواعد البيداغوجية المحلية، وتصدير `Word (.docx)` تعمل **محلياً بالكامل بدون مفتاح وبدون إنترنت**.
- لتفعيل الميزات الاختيارية التي تستدعي خادم `Gemini` (مثل توليد مسودة جذاذة بالذكاء الاصطناعي أو تفريغ ملفات `PDF`):
  1. افتح تبويب **«الذكاء الاصطناعي»** داخل التطبيق.
  2. أدخل مفتاح `Gemini API` الخاص بك في الحقل المحمي (يُحفظ مشفراً عبر `Android Keystore AES-256-GCM`، أو في الذاكرة المؤقتة للجلسة فقط إذا تعذر الوصول إلى `Keystore`).
- بالنسبة للسكربتات المرجعية في `docs/scripts/`، يُمرَّر المفتاح عبر متغير البيئة فقط:
  ```bash
  export GEMINI_API_KEY="YOUR_OWN_API_KEY"
  ```
