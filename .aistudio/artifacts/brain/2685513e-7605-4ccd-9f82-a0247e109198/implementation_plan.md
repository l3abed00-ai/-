# خطة إعادة بناء محرك التفريغ ومولّد الجذاذات النموذجية

## 1. نظرة عامة على التصميم والهيكل الرسمي
تهدف هذه التحديثات إلى توحيد مخرجات التطبيق (في الواجهة وملفات Word المصدّرة `.docx`) لتطابق 100% القالب الرسمي ذي الأعمدة الخمسة من اليمين إلى اليسار (RTL) للمكونات الثلاثة: **النصوص القرائية**، و**الدرس اللغوي**، و**التعبير والإنشاء**، مع استيعاب جميع أشكال الجذاذات المصدرية (سواء كانت من عمودين، أو 4، أو 8، أو 9 أعمدة، وبأي اتجاه RTL/LTR).

### القيم الافتراضية القابلة للتعديل في الترويسة (`JadhadhaInfo`)
- **الأستاذ**: `محمد العابد` (افتراضي قابل للتعديل)
- **المؤسسة**: `مدرسة أنوال (السلك الإعدادي)` (افتراضي قابل للتعديل)
- **المرجع**: `المختار في اللغة العربية` (افتراضي قابل للتعديل)
- **الفئة المستهدفة**: `السنة الثالثة إعدادي` (افتراضي قابل للتعديل)
- **الوسائل التعليمية**: `السبورة - كتاب المتعلم (ة) – دفتر المتعلم (ة).`
- **الكفايات المستهدفة / الأهداف التعلمية**:
  - `كفاية تواصلية`
  - `كفاية منهجية`
  - `كفاية معرفية`

## 2. تفاصيل التنفيذ حسب المحاور الأربعة

### المحور الأول: تصفير الذاكرة وتحديث النماذج (`AppDatabase.kt` و `SamplePlans.kt` و `JadhadhaModels.kt`)
1. **قاعدة البيانات والإعدادات (`AppDatabase.kt` و `MainActivity.kt`)**:
   - رفع إصدار قاعدة البيانات في `AppDatabase.kt` مع تفعيل `.fallbackToDestructiveMigration()` لمسح الجذاذات القديمة تلقائياً.
   - إضافة زر باللون الأحمر **"حذف جميع الجذاذات المخزنة"** داخل نافذة الإعدادات مع رسالة تأكيد لمسح البيانات المخزنة في أي وقت.
2. **تحديث نموذج البيانات (`JadhadhaModels.kt`)**:
   - إضافة حقول الترويسة الجديدة القابلة للتعديل (`reference`, `teacherName`, `schoolName`) إلى `JadhadhaInfo`.
   - دعم الجداول الفرعية المدمجة داخل عمود المحتوى (`EmbeddedTable` أو تمثيل الجداول المدمجة داخل `content`) لعرضها كجداول حقيقية في المعاينة وملف الـ Word.
   - تحديث `StageCatalog` ليطابق المراحل الرسمية لكل مكون:
     - **النصوص القرائية (حصتان - 7 صفوف مراحل)**:
       - الحصة الأولى (`تأطير النص والقراءة التوجيهية`): `تشخيص المكتسبات` ← `ملاحظة النص` ← `فهم النص`.
       - الحصة الثانية (`القراءة التحليلية والتركيبية`): `تمهيد` (صف مستقل ببداية الحصة الثانية) ← `القراءة التحليلية` ← `التركيب` ← `الاستثمار`.
     - **الدرس اللغوي (4 مراحل)**:
       - `تقويم تشخيصي` ← `ملاحظة الأمثلة ووصفها وتحليلها` (شاملة جداول الأمثلة التوضيحية + الاستنتاج الجزئي + التقويم التكويني) ← `الاستنتاج` (شاملاً القاعدة والنموذج الإعرابي) ← `تطبيق`.
     - **التعبير والإنشاء (4 حصص مستقلة)**:
       - `حصة الاكتساب` (5 مراحل): `تقويم تشخيصي` ← `قراءة نص الانطلاق وفهمه` ← `استخراج عناصر الدرس` ← `الاستنتاج` ← `الاستثمار`.
       - `حصة التطبيق` (4 مراحل): `تقويم تشخيصي (تمهيد)` ← `تقديم الدرس` ← `إنجاز المهارة` ← `تصحيح`.
       - `حصة الإنتاج` (4 مراحل): `تقويم تشخيصي (تمهيد)` ← `تقديم الدرس` ← `إنجاز المهارة` ← `تصحيح`.
       - `حصة التصحيح` (3 مراحل): `تقويم تشخيصي (تمهيد)` ← `تشخيص أخطاء المتعلمين وتصنيفها` (مع جدول شبكة تشخيص الأخطاء المدمج) ← `التصحيح الفردي والدعم والتعزيز`.
3. **النماذج الرسمية الثلاثة (`SamplePlans.kt`)**:
   - استبدال النماذج الحالية بالنماذج الثلاثة المرفقة بكامل نصوصها وجداولها الفرعية:
     1. **النصوص القرائية**: `"المنفى"` (حصتان كاملتان مع صف `تمهيد` في بداية الحصة الثانية).
     2. **الدرس اللغوي**: `"اسم الفاعل وعمله (صيغ المبالغة)"` (مع جدولي `المجموعة 1` و`المجموعة 2` المدمجين داخل مرحلة الملاحظة والتحليل).
     3. **التعبير والإنشاء**: `"التدرب على كتابة يوميات"` (الحصص الأربع كاملة: الاكتساب، التطبيق، الإنتاج، التصحيح مع جدول `"شبكة تشخيص أخطاء المتعلمين وتصحيحها"`).

### المحور الثاني: بناء مولّد الـ Word الرسمي ذي الـ 5 أعمدة (`DocxGenerator.kt`)
1. **اتجاه الجداول (RTL 100%)**:
   - تضمين `<w:bidiVisual/>` في `<w:tblPr>` لجميع الجداول (الرئيسية والفرعية والترويسة)، وتضمين `<w:bidi/>` في `<w:pPr>` و`<w:rPr>`.
2. **جدول الترويسة العلوية (`#F2F2F2`)**:
   - بناء جدول ترويسة من 7 صفوف و4 أعمدة بخلفية رمادية فاتحة `#F2F2F2`:
     - اليمين: `الوحدة`، `المجال`، `المكون`، `الموضوع`، `مدة الإنجاز`، `المرجع`، `الأستاذ`.
     - اليسار: `الفئة المستهدفة`، `الوسائل التعليمية`، `الكفايات المستهدفة / الأهداف التعلمية` (`كفاية تواصلية`، `كفاية منهجية`، `كفاية معرفية`)، `المؤسسة`.
3. **الجدول الرئيسي من 5 أعمدة (من اليمين لليسار)**:
   - العمود 1 (**12%**): `المراحل` / `المقاطع`
   - العمود 2 (**18%**): `القدرات والمهارات`
   - العمود 3 (**25%**): `الأنشطة التعليمية التعلمية`
   - العمود 4 (**30%**): `المحتوى` (يدعم النصوص المنسقة والجداول الفرعية المدمجة `<w:tbl>` داخل الخلية مثل جداول المجموعات وشبكة تشخيص الأخطاء)
   - العمود 5 (**15%**): `التقويم والدعم`
4. **تصدير الحصص المتعددة في التعبير والإنشاء**:
   - عند تصدير جذاذة "التعبير والإنشاء" المكونة من 4 حصص، يتم توليد **جدول ترويسة مستقل + جدول مراحل من 5 أعمدة لكل حصة** (`حصة الاكتساب`، `حصة التطبيق`، `حصة الإنتاج`، `حصة التصحيح`).

### المحور الثالث: محرك التفريغ الذكي والتحويل الهيكلي (`DocumentFileReader.kt` و `JadhadhaParser.kt`)
1. **قراءة XML النظيفة والدقيقة (`DocumentFileReader.kt`)**:
   - إزالة جميع وسوم التنسيق مثل `<u>`, `</u>`, `<b>`, `</b>` نهائياً.
   - إضافة مسافة بين عناصر `<w:t>` المتتالية وسطر جديد بين فقرات `<w:p>` لمنع التصاق الكلمات.
   - حساب الفهرس الفعلي للأعمدة عبر تتبع `<w:gridSpan>` (الدمج الأفقي) و`<w:vMerge>` (الدمج العمودي).
   - استخراج أي جدول متداخل `<w:tbl>` داخل خلية `<w:tc>` كجدول فرعي مهيكل داخل حقل `المحتوى` للمرحلة بدلاً من معاملته كجدول مراحل مستقل.
2. **عزل الترويسة وتصفية الأعمدة الزائدة (`JadhadhaParser.kt`)**:
   - استخراج بيانات الترويسة (`الفئة المستهدفة`، `الوحدة`، `المجال`، `المكون`، `الموضوع`، `الحصيص الزمني/مدة الإنجاز`، `الوسائل`، `الكفايات والأهداف`) حصرياً إلى `JadhadhaInfo` ومنع تسربها لخلايا المراحل.
   - استبعاد عمودي `الحصيص الزمني` (`5 د`، `35 د`...) و`مقاطع الدرس` (`المقطع التمهيدي`، `المقطع الوسيطي`، `المقطع النهائي`) من التدفق إلى المحتوى أو الأنشطة.
3. **خريطة دمج الأعمدة (من 8 أو 9 أعمدة إلى 5 أعمدة نموذجية) بأي اتجاه RTL/LTR**:
   - فحص أول صفين في الجدول لتحديد هوية كل عمود مهما كان ترتيب الأعمدة:
     - `القدرات` / `القدرات المستهدفة` ← **القدرات والمهارات** (`abil`).
     - `أنشطة المدرس` + `أنشطة المتعلمين` ← يدمجان في **الأنشطة التعليمية التعلمية** (`teacher`).
     - `محتوى التعلمات` ← **المحتوى** (`content` مع الحفاظ على الجداول الفرعية المدمجة).
     - `التقويم / الدعم` + `مؤشرات التقويم` ← يدمجان في **التقويم والدعم** (`eval`).
4. **قواعد تسكين المراحل حسب المكون**:
   - تطبيق خوارزمية التسكين المخصصة لكل مكون (النصوص القرائية، الدرس اللغوي، التعبير والإنشاء بحصصه الأربع شاملة تحويل حصة التصحيح ذات العمودين إلى 3 مراحل داخل الجدول الخماسي).
